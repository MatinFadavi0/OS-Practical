# آماده‌سازی لینوکس

از لینوکس روی سیستم اصلی یا ماشین مجازی استفاده کنید. فایل‌ها روی همان
ماشین کامپایل می‌شوند و هر دو معماری amd64 و arm64 قابل استفاده‌اند.
محیط بومی macOS محیط ارزیابی نیست.
نصب داکر برای ساخت کد اولیه یا اجرای آزمون‌ها لازم نیست.

در Debian/Ubuntu ابزارها را یک بار نصب کنید:

```sh
sudo apt update
sudo apt install build-essential python3 bash procps git
```

پس از آماده‌سازی، ساخت برنامه و آزمون‌ها به sudo یا
اتصال شبکه نیاز ندارند. ابزارهای تمرین به Python 3.10 یا جدیدتر نیاز دارند
و فقط از کتابخانهٔ استاندارد آن استفاده می‌کنند. نیازی به نصب بسته با pip،
دریافت ایمیج داکر، ساخت هسته، strace یا ابزار کمکی اختصاصی ندارید.

```sh
git clone https://github.com/MohammadAminKoohi/OS-Practical.git
cd OS-Practical
git switch --detach hw02-v1.0.1
make -C assignments/hw02/q2 CC=gcc
python3 tests/hw02/test_langar.py
```

کد اولیه کامپایل می‌شود اما عمداً ناقص است: فقط آزمون خط فرمان باید عبور
کند و امتیاز عملکردی اولیه ۵ از ۱۰۰ است. برای عبور از سایر آزمون‌ها، فایل
`src/run.c` را تکمیل کنید. [راهنمای آزمون‌ها](../tests/hw02/README.fa.md)
را ببینید.

پس از دریافت نسخه، برای نگهداری تغییرات خود یک شاخه بسازید:

```sh
git switch -c my-hw02
```

در مراحل بعد، پیاده‌سازی خود را نگه دارید و راهنمای به‌روزرسانی همان مرحله
را دنبال کنید؛ کد خود را با فایل اولیهٔ جدید جایگزین نکنید.
