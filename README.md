# Operating Systems Practical Assignments

Student resources for the Operating Systems course. Assignment materials will be
published here as the course progresses.

Each release will include English and Persian instructions, the required starter
files, and any public tests or tools for that assignment. Follow the instructions
and release tag named in the course announcement.

The first assignment release is being prepared.

## تمرین‌های عملی سیستم‌عامل

این مخزن شامل منابع مورد نیاز دانشجویان برای تمرین‌های عملی درس سیستم‌عامل است.
محتوای هر تمرین به‌تدریج و هم‌زمان با پیشرفت درس منتشر می‌شود.

هر نسخه شامل صورت تمرین به زبان‌های فارسی و انگلیسی، فایل‌های اولیه و آزمون‌ها
یا ابزارهای عمومی مورد نیاز آن تمرین خواهد بود. برای دریافت نسخهٔ درست، راهنمای
تمرین و برچسب نسخهٔ اعلام‌شده در سامانهٔ درس را دنبال کنید.

اولین مجموعهٔ تمرین در حال آماده‌سازی است.
